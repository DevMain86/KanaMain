# KanaMain

> Learn hiragana and katakana: study by row, then test yourself in a timed typing game.

**Status:** in development (Phase 1: front end)

## What it is

KanaMain is a full-stack TypeScript web app for beginners learning Japan's two kana scripts. Students study each row, play a timed romaji-typing game and earn badges for flawless runs.

## Planned features

- **Study page:** every hiragana and katakana card, grouped by row, with filters, mark-complete tracking and spoken audio
- **Typing game:** first-guess scoring, streaks, flip-to-reveal and personal bests for each filter combination
- **Badges:** 11 achievement badges with furigana
- **Accounts (Phase 2):** sign-in and cross-device progress
